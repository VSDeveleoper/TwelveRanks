# Partner Center identity

These values are assigned to Twelve Ranks in Microsoft Partner Center and must
be used unchanged for Microsoft Store packages.

| Field | Value |
| --- | --- |
| Package identity name | `46146A.Sharaf.TwelveRanks12x12Chess` |
| Package publisher | `CN=739C94CA-22F6-47C5-938D-9709BCF78641` |
| Publisher display name | `A. Sharaf` |
| Package family name | `46146A.Sharaf.TwelveRanks12x12Chess_v9e8rz8bts36t` |
| Store ID | `9N8F63GHW5PH` |

The Store ID identifies the Partner Center product and is not an MSIX manifest
attribute. After the product is live, its Store URLs can use that ID:

- `ms-windows-store://pdp/?ProductId=9N8F63GHW5PH`
- `https://apps.microsoft.com/detail/9N8F63GHW5PH`
